# El Niño 1997-98 vs. hoy

Visualización comparativa de las anomalías de temperatura superficial del mar en el océano Pacífico durante el evento El Niño 1997-98 y un evento reciente.

## Objetivo

Generar una animación que permita explorar y comparar la evolución espacial de las anomalías de temperatura superficial del mar durante ambos periodos.

## Tecnologías

- Python
- NumPy
- Pandas
- Matplotlib
- Cartopy
- imageio-ffmpeg

## Ejecución

El script principal es `el_nino_1997_vs_hoy.py`.

Antes de ejecutarlo, instala las dependencias de Python y configura la ruta del archivo de datos requerido por el programa.

## Datos

El programa utiliza datos de temperatura superficial del mar y calcula o representa anomalías para comparar ambos periodos. Consulta la fuente y las condiciones de uso de los datos antes de redistribuirlos.
